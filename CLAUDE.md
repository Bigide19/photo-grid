# Photo Grid Composer

Static single-page tool that crops photos into squares and composes them into a grid image. All processing is client-side.

## Run

Open `index.html` directly in a browser. No build step.

## Stack

- Vanilla JS + Canvas API
- Google Fonts (Fraunces, JetBrains Mono) — only external dependency
- Single file: `index.html` (HTML + CSS + JS inlined)
