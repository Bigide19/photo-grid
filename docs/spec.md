# Photo Grid Composer — 작업 지침서

## 프로젝트 개요

여러 장의 사진을 정사각형으로 크롭한 뒤, 격자 형태로 합쳐 한 장의 이미지로 내보내는 정적 웹 도구.

- **단일 HTML 파일** (`index.html`) 한 개로 동작. 빌드 불필요.
- 모든 처리는 **클라이언트 사이드**에서 실행 (사진은 서버로 전송하지 않음).
- 외부 라이브러리 없이 **Vanilla JS + Canvas API**로 구현.
- GitHub Pages 등 정적 호스팅에 그대로 올릴 수 있어야 함.

## 핵심 기능 명세

### 1. 그리드 레이아웃 선택

2가지 프리셋을 버튼으로 제공한다.

| 사진 수 | 배치 |
|---|---|
| 4 | 2 × 2 |
| 9 | 3 × 3 |

- 기본값: 4 (2×2)
- 선택된 버튼은 시각적으로 활성 상태 표시
- 변경 시 이미 업로드된 사진은 유지하되, 필요한 최소 장수만 표시

### 2. 사진 업로드

- 클릭으로 파일 선택 + 드래그&드롭 모두 지원
- 다중 파일 선택 가능 (`<input multiple>`)
- 지원 포맷: JPG, PNG, WEBP
- 업로드 즉시 썸네일로 표시 (정사각형 미리보기)
- 사진 개수 카운터 표시 (`3 / 4 photos`)

### 3. 썸네일 영역

- 그리드 형태로 썸네일 표시
- 각 썸네일에:
  - 좌상단: 순서 번호 (1, 2, 3...)
  - 우상단: 삭제 × 버튼
  - 우하단: 크롭 적용된 경우 `CROPPED` 뱃지
- **드래그로 순서 변경** 가능 (HTML5 Drag and Drop API)
- 썸네일 클릭 시 크롭 모달 열림

### 4. 크롭 기능 (핵심)

크롭은 **정사각형 비율 고정**이다.

#### 크롭 모달 동작
- 썸네일 클릭 → 모달 오픈
- 모달 내부에 사진 표시 + 정사각형 크롭 박스 오버레이
- 크롭 박스 초기값:
  - 처음 여는 경우: 사진 가운데 기준, 짧은 변 길이로 최대 정사각형
  - 이전에 크롭한 적 있으면: 이전 좌표 복원

#### 크롭 박스 조작
- **드래그로 이동**: 박스 본체를 잡고 이동 (이미지 경계 밖으로 못 나감)
- **모서리 핸들로 리사이즈**: 4개 모서리(TL, TR, BL, BR)에 핸들. 드래그 시 정사각형 비율 유지하며 크기 변경
- 모서리 핸들 중 가까운 두 축의 변화량 중 큰 쪽을 기준으로 크기 변경
- 최소 크기: 20px (이미지 픽셀 기준)
- 경계 처리: 박스가 이미지 밖으로 나가면 자동으로 클램프

#### 시각적 보조
- 크롭 박스 외부는 어둡게 처리 (`box-shadow: 0 0 0 9999px rgba(0,0,0,0.5)`)
- 박스 내부에 **3분할 가이드라인** (가로 2줄, 세로 2줄)
- 모서리 핸들은 원형 + 강조 색상 테두리

#### 모달 액션
- `Cancel`: 변경 사항 폐기
- `Apply`: 현재 크롭 좌표를 `crop: {x, y, size}`로 저장 (이미지 원본 픽셀 기준 좌표)

### 5. 그리드 합치기 (Compose)

- 모든 셀이 사용된 사진 중 가장 작은 크롭 크기로 통일됨 (`cellSize = min(sizes)`)
- 크롭이 적용된 사진: 저장된 `{x, y, size}`로 원본에서 잘라냄
- 크롭이 없는 사진: 가운데 정사각형 자동 크롭
- 캔버스 크기: `cellSize × cols`, `cellSize × rows`
- 각 셀에 사진을 그릴 때 `drawImage(src, sx, sy, ss, ss, dx, dy, cellSize, cellSize)`로 처리
- 결과는 `<img>`로 미리보기 + `Download PNG` 버튼

### 6. 다운로드

- `canvas.toDataURL('image/png')`로 PNG 생성
- 파일명: `photo-grid-{cols}x{rows}-{timestamp}.png`
- 미리보기 영역 아래에 메타 정보 표시 (`2400 × 2400 px · 2×2 grid`)

### 7. 리셋

- `Reset` 버튼: 사진이 있으면 confirm으로 확인, 모두 초기화

### 8. 강조색 선택

- 사용자가 머스터드 / 테라코타 / 올리브 중 선택 가능
- 헤더 영역에 작은 스와치 토글로 제공

## 데이터 구조

```js
// 사진 단위
{
  id: string,         // crypto.randomUUID()
  img: HTMLImageElement,  // 로드된 원본 이미지
  crop: null | {      // null이면 자동 가운데 크롭
    x: number,        // 원본 픽셀 기준
    y: number,
    size: number      // 정사각형 한 변 길이
  },
  originalFile: File
}

// 전역 상태
let targetCount = 4 | 9
let photos = []  // 위 객체의 배열
let editingId = null  // 크롭 모달이 열려있을 때 대상 id
```

## UI/UX 가이드라인

### 디자인 톤
- **lofi / cozy / 종이 질감** 느낌
- 따뜻한 베이지 톤 배경 + 차분한 톤
- 강조색: 머스터드 / 테라코타 / 올리브 중 사용자 선택
- 폰트: Google Fonts에서 **세리프 1종 (Fraunces)** + **모노스페이스 1종 (JetBrains Mono)** 조합
- 일반적인 SaaS 톤 (보라 그라디언트, Inter, 흰 배경) 회피

### 레이아웃
- 최대 너비 1100px, 가운데 정렬
- 3개 패널을 위에서 아래로:
  1. `01 / Layout` — 그리드 선택
  2. `02 / Photos` — 업로드 + 썸네일
  3. `03 / Output` — 액션 버튼 + 결과 미리보기
- 패널 라벨은 모노스페이스 + 작은 크기 + 강조선

### 반응형
- 모바일에서도 정상 동작 (터치 이벤트 = `pointerdown/move/up` 사용 권장)
- 크롭 모달이 작은 화면에서도 사용 가능해야 함

## 기술 제약

- **외부 라이브러리 사용 금지** (jQuery, React, Tailwind 등 모두 제외). Google Fonts CDN만 허용.
- **빌드 도구 사용 금지**. `index.html` 한 파일로 완성.
- ES2020+ 문법 사용 OK (`?.`, `??`, `crypto.randomUUID()` 등)
- `localStorage` 사용 금지 (현재는 세션 기반으로 충분)
- 이벤트는 **Pointer Events** 통일 (마우스/터치 모두 커버)

## 엣지 케이스 처리

1. **사진이 부족할 때**: `Compose Grid` 버튼 비활성화 + 카운터로 안내
2. **사진이 너무 많을 때**: 처음 N장만 사용 (초과분은 무시, 썸네일에는 표시되지만 합성 시 제외)
3. **크롭 박스가 이미지보다 작아질 때**: 최소 20px 보장
4. **거대 이미지**: 크롭 모달의 캔버스는 화면에 맞게 축소 표시하되, 실제 크롭 좌표는 원본 픽셀 기준으로 저장
5. **세로 사진 + 가로 사진 혼합**: 셀이 정사각형이라 자동으로 통일됨
6. **중복 업로드**: 별도 처리 없이 그대로 추가 (사용자가 직접 삭제)
